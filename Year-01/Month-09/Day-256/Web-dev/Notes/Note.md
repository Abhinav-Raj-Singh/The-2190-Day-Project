# Flexbox

1. `align-self`: when wanted to arrange a `child` in `flexbox` and in this you don't need to create that `child` a `container` using `display:flex`. And this will directly move `child` in the whole `parent container`. And `movement` will also depends on `parent` `container` `flex-direction` if `row` then `top` and `bottom` movement is only allowed and if `column` then `left` and `right`. Also make sure their is enough dimensions `space` in which you wanted to move otherwise increase that dimension.
