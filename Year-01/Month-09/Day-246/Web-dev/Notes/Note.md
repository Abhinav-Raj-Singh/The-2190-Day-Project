# Introduction to Flexbox

1. `What is flexbox`: this is a revolutionary tool in `CSS` that helps to increase our efficiency in while using `css`.

2. `Inspect`: when anything on any website is not going the way it is then `inspect` that `web page`.

3. `Flex containers and flex items`: `flexbox` is a whole toolbox of `properties` from which some properties goes to `flex containers` and some on `flex items` . `flex container` is any element which has `display: flex` wherease items live inside that `flex container` are `flex items` . Even you can put `display: flex` on `flex items` to use them as `flex container` means they can be both `flex container and even flex item`. Creatnig and nesting multuiple `flex containers and items` is the primary way we build up complex layouts.
