# My Own hands on learning On HTML

1. `Line break`: when you wanted to `break lines` in `p` `tag` in `HTML` then the point from where you wanted to end current line put `<br/>` this will `break` that line from that exact point.

#  My Own hands on learning On CSS

1. `Moving things relatively`: when you wanted to move any text left and right then instead of using `margins` use `position: relative` and then `right: 20px` this will move text to right hand side.

#  My Own hands on learning On Git

1. `merge branch with main`: open that `branch ` then click on `merge status` and then `merge pull request` then enter `commit message` and `extended description` and then click on `confirm merge`.

2. `sync just merged repo with repo on your local machine`: switch to `main branch` in `local repo` then type `git pull origin main`.
